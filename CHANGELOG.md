# Changelog

## 0.1.0 — 2026-03-27

Initial release.

- Three interview modes: system design, coding, behavioral (plus full-loop)
- Four difficulty levels: mid, senior, staff, principal
- Real code execution: Python, SQL (DuckDB), Rust, JavaScript
- System design diagram DSL with ASCII and Mermaid rendering
- Five pluggable LLM providers: Ollama, OpenAI, Anthropic, Claude CLI, Codex CLI
- LLM-based scoring across five dimensions per mode
- SM-2 spaced repetition for progress tracking
- TOML challenge bank with 8 built-in challenges
- Textual TUI with timer, code editor, score panel, STAR tracker
- SQLite progress database with export (JSON/CSV)
